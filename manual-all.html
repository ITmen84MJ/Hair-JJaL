    고객 사용 매뉴얼

    예약 · 시술 이력 확인 · 공유 링크 안내

    Rev. 1.0  |  2026년

    1

    시작하기 — 로그인

    계정 받기

    고객 계정은 헤어샵 직원이 직접 발급합니다. 방문 시 담당 디자이너 또는 원장에게 계정 생성을 요청하세요. 가입 완료 후 이메일과 임시 비밀번호를 안내받습니다.

    첫 로그인

    1
    앱 주소 접속

    브라우저에서 샵으로부터 받은 주소를 입력하거나 북마크를 탭합니다.

    2
    이메일 · 비밀번호 입력 후 로그인 탭

    이메일은 대소문자를 구분하지 않습니다.

    3
    고객 홈 화면 진입 확인

    상단에 샵 이름과 내 이름이 표시되면 로그인 성공입니다.

    💡
    비밀번호를 잊었거나 로그인이 안 된다면 담당 직원에게 계정 재설정을 요청하세요. 현재 버전에서는 셀프 비밀번호 재설정을 지원하지 않습니다.
    2

    홈 화면 둘러보기

    메인 탭 구성

    탭 이름주요 기능
    홈최근 시술 요약, 다음 방문 예정일, 매장 연락처 · 위치
    예약신규 예약 신청, 예약 내역 확인, 예약 취소
    시술 이력전체 시술 기록 목록 및 상세 정보
    ℹ️
    화면 오른쪽 상단의 ☀ / ☾ 아이콘을 탭하면 다크 모드와 라이트 모드를 전환할 수 있습니다.

    홈 탭 — 매장 정보 확인

    홈 탭 하단의 내 지점 카드에서 매장 주소, 전화번호, 영업시간을 확인할 수 있습니다.

    • 전화번호 탭 → 바로 전화 연결
    • 주소 탭 → 카카오맵에서 길찾기
    3

    예약 신청하기

    신규 예약 작성

    1
    하단 예약 탭 → + 예약 신청 버튼

    예약 신청 폼이 열립니다.

    2
    원하는 날짜 · 시간 선택

    매장 영업시간 범위 내 30분 단위 슬롯이 표시됩니다.

    3
    시술 항목 선택

    컷 · 컬러 · 펌 등 원하는 시술을 하나 이상 선택합니다.

    4
    담당 디자이너 선택 (선택 사항)

    원하는 디자이너가 없으면 비워두면 매장에서 배정합니다.

    5
    요청 사항 입력 후 예약 신청

    특이사항(두피 예민, 시술 참고 이미지 설명 등)을 자유롭게 입력하세요.

    💡
    시술 이력에서 "이 날짜로 예약하기" 버튼을 탭하면 다음 방문 권장일이 미리 입력된 예약 폼으로 이동합니다.

    예약 상태 확인

    상태 배지의미
    대기예약 접수 완료, 매장 확인 전
    확정매장이 예약을 확인·승인함
    취소본인 또는 매장 측에서 취소함

    예약 취소

    1
    예약 탭에서 취소할 예약 카드 선택

    대기 상태 예약만 직접 취소 가능합니다.

    2
    예약 취소 버튼 탭 → 확인 팝업에서 취소 확인

    취소 후에는 되돌릴 수 없습니다. 재예약은 새로 신청하세요.

    ℹ️
    확정 상태 예약을 취소해야 한다면 매장에 직접 연락하여 취소를 요청하세요.
    4

    시술 이력 확인

    이력 목록

    하단 시술 이력 탭을 탭하면 나의 전체 시술 기록이 날짜 역순으로 표시됩니다. 각 카드에서 날짜, 시술 항목, 담당 디자이너를 한눈에 확인할 수 있습니다.

    상세 보기

    항목내용
    날짜 · 담당 스타일리스트시술 날짜와 담당 디자이너명
    시술 항목 · 금액컷, 컬러 등 세부 항목 및 총 금액
    Before / After 사진시술 전·후 사진 (담당자가 등록한 경우에만 표시)
    모발 · 두피 상태시술 당시 기록된 모발/두피 정보
    상담 메모담당 스타일리스트의 메모
    다음 방문 권장일다음 방문 추천 날짜와 메모
    💡
    상세 화면 하단의 "이 날짜로 예약하기" 버튼을 탭하면 권장 재방문일을 기반으로 예약 폼이 미리 채워집니다.
    5

    공유 링크로 이력 열기

    담당 스타일리스트가 특정 시술 이력을 공유하면 링크(URL)를 받을 수 있습니다. 이 링크는 로그인 없이 열 수 있습니다.

    1
    받은 링크를 브라우저에서 열기

    카카오톡, 문자 등으로 받은 URL을 탭합니다.

    2
    시술 상세 정보 확인

    Before/After 사진, 시술 항목, 포뮬러 정보 등을 볼 수 있습니다.

    3
    수정·삭제 요청 (선택)

    내용에 오류가 있으면 수정 요청 또는 삭제 요청 버튼으로 메시지를 전달할 수 있습니다.

    ℹ️
    공유 링크는 담당 스타일리스트가 비활성화하면 더 이상 열리지 않습니다. 공유가 끊긴 경우 직접 로그인하여 이력을 확인하세요.
    6

    앱 설치 (PWA)

    Hair JJaL은 스마트폰 홈 화면에 앱처럼 설치할 수 있습니다.

    Android (크롬)

    1
    크롬 주소창 오른쪽 ⋮ 메뉴 탭
    2
    "홈 화면에 추가" 선택 후 확인

    iPhone / iPad (사파리)

    1
    하단 툴바의 공유 버튼 (□↑) 탭
    2
    "홈 화면에 추가" 선택
    3
    이름 확인 후 오른쪽 상단 "추가" 탭
    💡
    홈 화면에 설치하면 앱처럼 전체 화면으로 실행되며, 주소창이 사라져 훨씬 편리하게 사용할 수 있습니다.
    7

    자주 묻는 질문 (FAQ)

    질문답변
    예약 신청 후 언제 확정되나요?매장 담당자가 확인 후 상태를 확정으로 변경합니다. 보통 영업시간 내 처리됩니다.
    이미 확정된 예약을 취소할 수 있나요?앱에서는 대기 상태만 직접 취소 가능합니다. 확정 예약은 매장에 직접 연락하세요.
    시술 이력이 보이지 않아요.담당 스타일리스트가 아직 이력을 등록하지 않은 것입니다. 담당자에게 문의하세요.
    비밀번호를 변경하고 싶어요.현재 버전에서는 직원에게 요청하여 재설정합니다.
    공유 링크가 열리지 않아요.공유가 비활성화된 것입니다. 로그인 후 시술 이력 탭에서 직접 확인하거나 담당자에게 재공유를 요청하세요.

    디자이너 사용 매뉴얼

    고객 관리 · 상담 이력 작성 · 예약 관리 · 프로필

    Rev. 1.0  |  2026년

    1

    로그인 · 계정 관리

    로그인

    1
    앱 주소 접속 → 이메일 · 비밀번호 입력

    원장이 발급한 이메일 계정으로 로그인합니다.

    2
    로그인 후 대시보드 진입 확인

    사이드바(데스크탑) 또는 하단 탭바(모바일)에서 내비게이션을 확인합니다.

    ℹ️
    매니저 권한이 부여된 경우 사용자 이름 아래 매니저 배지가 표시됩니다. 매니저는 지점 전체 고객 데이터를 열람할 수 있습니다.

    이름 · 연락처 변경

    사이드바 하단 내 정보 → ✎ 수정 버튼에서 이름과 연락처를 변경할 수 있습니다. 이메일 변경은 원장에게 요청하세요.

    2

    대시보드

    통계 카드

    카드내용
    전체 고객내가 담당한 고객 총 수
    이번 달 시술당월 내 담당 시술 건수
    이번 달 매출당월 내 담당 시술 합산 금액
    예약 예정다음 방문 권장일이 설정된 예약 수
    ℹ️
    일반 디자이너(staff)는 본인이 시술한 이력만 집계됩니다. 매니저는 지점 전체 합산으로 표시됩니다.

    오늘의 예약

    오늘 날짜에 확정 또는 대기 상태인 예약이 있으면 대시보드 상단에 카드 형태로 표시됩니다. 전체보기를 탭하면 예약 관리 화면으로 이동합니다.

    최근 상담 이력 · 다음 방문 예정

    최근 5건의 시술 이력과 다음 방문 권장일이 임박한 고객 3명이 표시됩니다. 카드를 탭하면 해당 고객 또는 상담 상세 화면으로 바로 이동합니다.

    3

    고객 관리

    고객 추가

    1
    고객 관리 → + 고객 추가
    2
    이름 · 전화번호 입력 (필수)

    이메일, 생년월일, 메모, 태그는 선택 입력입니다.

    3
    저장 탭 → 고객 목록에 추가 확인
    💡
    태그를 적극 활용하세요. 예: VIP, 민감성, 펌 전문 등 태그를 붙이면 나중에 필터 검색이 편리합니다.

    고객 검색 · 정렬 · 필터

    검색창에 이름, 전화번호(숫자만 입력 가능), 이메일을 입력하면 실시간 필터링됩니다.

    정렬 옵션설명
    최근방문순 (기본)마지막 시술일이 가장 최근인 고객 순
    이름순가나다 순
    방문많은순총 시술 건수가 많은 고객 순

    검색창 옆 🔽 필터 버튼으로 시술 종류·태그 기준 복합 필터링이 가능합니다. 필터가 활성화되면 버튼이 빨간색으로 변합니다.

    고객 삭제

    고객 카드 하단의 🗑 삭제 버튼 → 확인 모달에서 삭제를 탭합니다.

    ⚠️
    고객 삭제 시 해당 고객의 모든 시술 이력이 함께 삭제됩니다. 이 작업은 되돌릴 수 없습니다.
    4

    고객 상세 · 시술 이력

    고객 상세 화면 구성

    탭내용
    이력시술 이력 목록. 날짜·시술명·금액 카드 형태로 표시
    사진 갤러리Before/After 사진 타임라인. 클릭 시 라이트박스
    통계방문 횟수·누적 금액, 월별 방문 차트, 시술 분포 차트

    CSV 내보내기 · 고객 정보 수정

    고객 상세 헤더의 ⬇ CSV 버튼으로 해당 고객 전체 이력을 엑셀 호환 파일로 내보내고, ✎ 버튼으로 이름·전화번호·이메일·태그·메모를 수정합니다.

    5

    상담 이력 작성

    새 이력 작성 시작

    1
    고객 상세 화면 → + 상담 이력 추가
    2
    이전 이력 자동 채우기 (선택)

    재방문 고객이면 이전 값으로 채우기 버튼이 표시됩니다. 탭하면 직전 시술 정보가 채워져 수정만 하면 됩니다.

    각 섹션 입력 요령

    섹션입력 내용 및 팁
    기본 정보날짜(기본: 오늘), 스타일리스트 이름(필수). 드롭다운에서 지점 디자이너 선택.
    시술 항목종류 선택 → 설명 입력 → 금액 입력. + 항목 추가로 여러 시술을 동시에 기록.
    Before / After 사진사진 영역 탭 → 카메라 또는 갤러리. 자동으로 압축되므로 원본 고해상도 그대로 업로드해도 됩니다.
    모발 · 두피 상태텍스트 직접 입력 또는 🎤 버튼으로 음성 입력.
    시술 포뮬러컬러·펌 포뮬러를 기록. 🎤 음성 입력 지원. 저장된 포뮬러 템플릿에서 불러오기 가능.
    상담 메모고객 특이사항, 다음 방문 참고 사항 자유 기록. 🎤 음성 입력 지원.
    다음 방문 예정권장 재방문일을 입력하면 대시보드와 고객 홈에 알림 카드가 표시됩니다.

    포뮬러 템플릿 저장 · 불러오기

    1
    포뮬러 입력 후 💾 템플릿 저장 탭

    템플릿 이름(예: "내추럴 브라운 6N+8%")을 입력하고 저장합니다.

    2
    다음 작성 시 📂 템플릿 버튼 → 목록에서 선택
    3
    불필요한 템플릿은 목록 옆 🗑 버튼으로 삭제
    💡
    포뮬러 템플릿은 이 기기의 브라우저에 저장됩니다. 자주 쓰는 기기에서 저장하는 것을 권장합니다.

    작성 중 이탈 방지

    • 모달 닫기 → "작성 중인 내용이 있습니다. 닫으시겠어요?" 확인 팝업
    • 브라우저/탭 닫기 → 브라우저 기본 이탈 경고
    6

    상담 이력 상세 · 공유

    상세 화면 버튼

    버튼기능
    🖨 인쇄브라우저 인쇄 다이얼로그 열기 (시술 카드 형태)
    ✎ 수정이력 수정 폼 열기
    🗑 삭제이력 삭제 (확인 후 완전 삭제)

    고객 수정·삭제 요청 처리

    고객이 공유 링크를 통해 수정 또는 삭제 요청을 남기면 상세 화면 상단에 노란색 경고 배너가 표시됩니다. 처리 후 처리 완료 버튼을 탭하면 배너가 사라집니다.

    고객 공유 링크 발급

    1
    상세 화면 하단 고객 공유 섹션 → 토글 켜기
    2
    복사 버튼 → 링크를 카카오톡·문자 등으로 전달
    3

    자주 묻는 질문 (FAQ)

    질문답변
    다른 디자이너 고객이 목록에 보이지 않아요.일반 디자이너(staff)는 본인 담당 고객만 표시됩니다. 전체 고객을 보려면 원장에게 매니저 권한을 요청하세요.
    포뮬러 템플릿이 사라졌어요.템플릿은 브라우저 localStorage에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기에서 접속하면 보이지 않습니다.
    작성 중인 이력이 실수로 닫혔어요.저장 전 작성 내용은 복구되지 않습니다. 이탈 방지 확인 팝업이 뜰 때는 반드시 취소 후 저장하세요.
    음성 입력이 작동하지 않아요.브라우저 마이크 권한을 허용해 주세요. 주소창 왼쪽의 자물쇠 → 마이크 → 허용.
    사진을 올렸더니 화면이 느려요.업로드 시 자동 압축이 적용됩니다. 저장 후에는 정상입니다.

    데이터 관리

    저장 공간 게이지

    현재 앱 데이터가 사용 중인 저장 공간을 게이지 바로 표시합니다. 브라우저 localStorage 한계(약 5MB)에 가까워지면 빨간색으로 변하고 경고 토스트가 표시됩니다.

    ⚠️
    Before/After 사진을 많이 업로드하면 저장 공간이 빠르게 차오릅니다. 80% 이상 사용 시 정기적으로 JSON 백업 후 불필요한 데이터를 정리하세요.

    1
    📥 데이터 내보내기 버튼 클릭

    💡
    매주 또는 매월 백업 파일을 저장해 두세요. 기기 교체, 브라우저 초기화 등의 상황에서 복원할 수 있습니다.

    📤 데이터 가져오기 버튼 클릭 → 백업 파일 선택

    ⚠️
    가져오기는 현재 데이터를 모두 덮어씁니다. 기존 데이터를 먼저 내보내기로 백업한 후 진행하세요. 이 작업은 되돌릴 수 없습니다.

    자주 묻는 질문 (FAQ)

    질문답변
    직원이 비밀번호를 잊었어요.직원 관리에서 해당 직원의 비밀번호를 재설정(삭제 후 재등록 또는 초기화)할 수 있습니다.
    직원 이메일을 변경했는데 로그인이 안 돼요.이메일 변경과 동시에 로그인 계정도 변경됩니다. 변경된 이메일로 로그인하도록 안내하세요.
    데이터가 5MB를 넘을 것 같아요.즉시 JSON 백업을 받아두고, 오래된 Before/After 사진이 있는 이력을 편집하여 사진을 제거하면 공간을 확보할 수 있습니다.
    기기를 교체하면 데이터가 사라지나요?네. 현재 데이터는 브라우저 localStorage에 저장됩니다. 새 기기에서 사용하려면 JSON 백업 → 새 기기에서 가져오기를 하세요.
    직원별 매출 비교를 볼 수 있나요?직원 관리 → 분석 탭 → 디자이너별 매출 비중 파이 차트에서 확인할 수 있습니다.
