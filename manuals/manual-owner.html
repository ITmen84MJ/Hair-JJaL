원장 계정 등록 · 로그인

첫 번째 사용 — 원장 계정 생성

1
앱 주소 접속 → 로그인 화면에서 원장 계정 만들기
2
지점 정보 입력

지점명(필수), 주소, 전화번호, 영업시간을 입력합니다.

3
원장 정보 입력

이름, 이메일, 비밀번호를 입력합니다. 이메일은 로그인 ID가 됩니다.

4
가입 완료 → 자동 로그인 및 대시보드 진입

로그인

이메일 · 비밀번호를 입력하고 로그인합니다. 사이드바에 원장 배지와 직원 관리 메뉴가 추가로 표시됩니다.

2

대시보드 (원장 전용)

지점 통합 통계 카드

카드내용
전체 고객지점에 등록된 고객 총 수
이번 달 시술지점 전체 당월 시술 건수
이번 달 매출지점 전체 당월 합산 금액
예약 예정다음 방문 권장일이 설정된 건수

오늘의 예약

오늘 날짜 확정/대기 예약 전체가 시간순으로 표시됩니다. 고객명, 담당 디자이너, 시간, 상태 배지를 확인할 수 있습니다.

원장 전용 분석 대시보드

사이드바 직원 관리 → 분석 탭(OwnerDashboard)에서 더 상세한 분석을 제공합니다.

섹션내용
월별 매출 추이최근 6개월 바 차트, 월별 시술 건수 추이
디자이너별 매출 비중파이 차트로 디자이너별 기여도 시각화
인기 시술 TOP 5가장 많이 시술된 항목 순위
3

직원 관리

디자이너 추가

1
직원 관리 → + 직원 추가
2
직원 정보 입력

이름(필수), 이메일(필수, 로그인 ID), 전화번호, 경력, 전문 분야, 권한(staff / manager)을 입력합니다.

3
초기 비밀번호 설정 후 추가

직원에게 이메일과 비밀번호를 별도 전달하세요.

💡
직원에게 계정을 전달할 때 비밀번호는 첫 로그인 후 변경하도록 안내하세요. (현재 버전에서는 원장이 비밀번호를 재설정합니다.)

권한 설명

권한열람 범위주요 차이점
staff (일반) 본인이 시술한 고객 + 이력만 타 디자이너 고객 데이터 비공개
manager (매니저) 지점 전체 고객 + 이력 부재 중 다른 직원 고객도 관리 가능
ℹ️
매니저는 사이드바 이름 아래 매니저 배지가 표시됩니다. 원장은 항상 지점 전체 데이터를 열람할 수 있습니다.

직원 정보 수정

직원 카드의 ✎ 수정 → 이름, 이메일, 전화번호, 권한 등 변경 후 저장.

⚠️
이메일 변경 시 주의: 이메일을 변경하면 해당 직원의 로그인 이메일이 즉시 새 이메일로 변경됩니다. 변경 전 직원에게 반드시 사전 안내하세요.

직원 비활성화 · 삭제

퇴직한 직원은 삭제하기 전 고려사항:

  • 삭제해도 해당 직원이 기록한 시술 이력은 보존됩니다.
  • 직원 레코드만 삭제되며, 이력의 스타일리스트명은 그대로 남습니다.
  • 로그인은 즉시 불가능해집니다.
1
직원 카드 → 🗑 삭제
2
확인 모달에서 삭제
4

고객 · 상담 이력 관리

원장의 고객 데이터 범위

원장은 지점에 등록된 모든 고객과 모든 시술 이력을 열람·수정·삭제할 수 있습니다. 디자이너 기능(고객 추가, 이력 작성, 공유 등)을 동일하게 사용할 수 있습니다.

ℹ️
고객 관리 · 상담 이력 작성 · 공유 링크 발급의 세부 사용법은 디자이너 매뉴얼 3~6장을 참고하세요. 원장도 동일한 방법으로 사용합니다.

전체 고객 CSV 내보내기

1
직원 관리 → 지점 정보 탭 → 데이터 관리 섹션
2
📊 전체 고객 CSV 버튼 클릭

전체 고객의 이름·전화번호·방문 횟수·마지막 방문일·태그를 엑셀 호환 CSV로 다운로드합니다.

5

예약 관리

원장의 예약 관리 범위

원장은 지점의 전체 예약을 열람·확정·취소할 수 있습니다. 사이드바의 대기 배지 숫자가 미확인 신규 예약 수를 나타냅니다.

예약 확정 처리

1
예약 관리 → 대기 탭에서 미확인 예약 확인
2
예약 카드 탭 → 상세 확인 → 확정 또는 취소

취소 시 사유를 입력하면 고객 예약 탭에 사유가 표시됩니다.

💡
매일 영업 시작 전 대기 탭을 확인하여 전날 밤 이후 접수된 예약을 처리하는 루틴을 만들어 두세요.
6

데이터 관리

데이터 관리 화면 접근

직원 관리 → 지점 정보 탭 → 하단 데이터 관리 섹션

저장 공간 게이지

현재 앱 데이터가 사용 중인 저장 공간을 게이지 바로 표시합니다. 브라우저 localStorage 한계(약 5MB)에 가까워지면 빨간색으로 변하고 경고 토스트가 표시됩니다.

⚠️
Before/After 사진을 많이 업로드하면 저장 공간이 빠르게 차오릅니다. 사진은 자동 압축되지만, 80% 이상 사용 시 정기적으로 JSON 백업 후 불필요한 데이터를 정리하세요.

JSON 전체 백업 (내보내기)

1
📥 데이터 내보내기 버튼 클릭

고객·이력·예약·직원·지점 데이터 전체가 hairjjal-backup-YYYY-MM-DD.json 파일로 다운로드됩니다.

💡
매주 또는 매월 백업 파일을 저장해 두세요. 기기 교체, 브라우저 초기화, 실수 삭제 등의 상황에서 복원할 수 있습니다.

JSON 백업 복원 (가져오기)

1
📤 데이터 가져오기 버튼 클릭 → 백업 파일 선택
2
유효성 검증 후 자동 페이지 재시작

올바른 백업 파일이면 데이터가 덮어씌워지고 앱이 재시작됩니다.

⚠️
가져오기는 현재 데이터를 모두 덮어씁니다. 기존 데이터를 먼저 내보내기로 백업한 후 진행하세요. 이 작업은 되돌릴 수 없습니다.

전체 고객 CSV 내보내기

📊 전체 고객 CSV 버튼을 클릭하면 모든 고객의 이름, 전화번호, 이메일, 방문 횟수, 마지막 방문일, 태그를 하나의 CSV 파일로 다운로드합니다. 엑셀에서 바로 열 수 있으며 한글 깨짐이 없습니다.

자주 묻는 질문 (FAQ)

질문답변
직원이 비밀번호를 잊었어요. 직원 관리에서 해당 직원의 비밀번호를 재설정(삭제 후 재등록 또는 초기화)할 수 있습니다. 새 비밀번호를 직접 전달하세요.
직원 이메일을 변경했는데 로그인이 안 돼요. 이메일 변경과 동시에 로그인 계정도 변경됩니다. 변경된 이메일로 로그인하도록 안내하세요.
데이터가 5MB를 넘을 것 같아요. 즉시 JSON 백업을 받아두고, 오래된 Before/After 사진이 있는 이력을 편집하여 사진을 제거하면 공간을 확보할 수 있습니다.
기기를 교체하면 데이터가 사라지나요? 네. 현재 데이터는 브라우저 localStorage에 저장됩니다. 새 기기에서 사용하려면 JSON 백업 → 새 기기에서 가져오기를 하세요.
직원별 매출 비교를 볼 수 있나요? 직원 관리 → 분석 탭 → 디자이너별 매출 비중 파이 차트에서 확인할 수 있습니다.
다른 지점을 추가로 운영하고 싶어요. 현재 버전에서는 계정당 지점 1개를 지원합니다. 복수 지점 운영은 추후 업데이트를 통해 지원될 예정입니다.
고객 예약 승인 알림을 자동으로 보낼 수 있나요? 현재 버전은 푸시 알림을 지원하지 않습니다. 예약 확정 후 카카오톡 등으로 직접 안내해 주세요.
