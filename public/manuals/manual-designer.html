로그인 · 계정 관리

로그인

1
앱 주소 접속 → 이메일 · 비밀번호 입력

원장이 발급한 이메일 계정으로 로그인합니다.

2
로그인 후 대시보드 진입 확인

사이드바(데스크탑) 또는 하단 탭바(모바일)에서 내비게이션을 확인합니다.

ℹ️
매니저 권한이 부여된 경우 사용자 이름 아래 매니저 배지가 표시됩니다. 매니저는 지점 전체 고객 데이터를 열람할 수 있습니다.

이름 · 연락처 변경

사이드바 하단 내 정보 → ✎ 수정 버튼에서 이름과 연락처를 변경할 수 있습니다. 이메일 변경은 원장에게 요청하세요.

2

대시보드

통계 카드

카드내용
전체 고객내가 담당한 고객 총 수
이번 달 시술당월 내 담당 시술 건수
이번 달 매출당월 내 담당 시술 합산 금액
예약 예정다음 방문 권장일이 설정된 예약 수
ℹ️
일반 디자이너(staff)는 본인이 시술한 이력만 집계됩니다. 매니저는 지점 전체 합산으로 표시됩니다.

오늘의 예약

오늘 날짜에 확정 또는 대기 상태인 예약이 있으면 대시보드 상단에 카드 형태로 표시됩니다. 고객명, 시간, 요청 사항을 한눈에 확인할 수 있습니다.

전체보기 를 탭하면 예약 관리 화면으로 이동합니다.

최근 상담 이력 · 다음 방문 예정

최근 5건의 시술 이력과 다음 방문 권장일이 임박한 고객 3명이 표시됩니다. 카드를 탭하면 해당 고객 또는 상담 상세 화면으로 바로 이동합니다.

3

고객 관리

고객 추가

1
고객 관리 → + 고객 추가
2
이름 · 전화번호 입력 (필수)

이메일, 생년월일, 메모, 태그는 선택 입력입니다.

3
저장 탭 → 고객 목록에 추가 확인
💡
태그를 적극 활용하세요. 예: VIP, 민감성, 펌 전문 등 태그를 붙이면 나중에 필터 검색이 편리합니다.

고객 검색 · 정렬

검색창에 이름, 전화번호(숫자만 입력 가능), 이메일을 입력하면 실시간 필터링됩니다.

정렬 옵션설명
최근방문순 (기본)마지막 시술일이 가장 최근인 고객 순
이름순가나다 순
방문많은순총 시술 건수가 많은 고객 순

필터 사용

검색창 옆 🔽 필터 버튼을 탭하면 필터 패널이 열립니다.

  • 시술 필터: 특정 시술(컷·컬러·펌 등)을 받은 이력이 있는 고객만 표시
  • 태그 필터: 선택한 태그가 붙은 고객만 표시 (AND 조건)

필터가 활성화되면 버튼이 빨간색으로 변하고 적용 개수 배지가 표시됩니다.

고객 삭제

고객 카드 하단의 🗑 삭제 버튼 → 확인 모달에서 삭제를 탭합니다.

⚠️
고객 삭제 시 해당 고객의 모든 시술 이력이 함께 삭제됩니다. 이 작업은 되돌릴 수 없습니다.
4

고객 상세 · 시술 이력

고객 상세 화면 구성

고객 목록에서 고객 카드를 탭하면 상세 화면이 열립니다.

탭내용
이력시술 이력 목록. 날짜·시술명·금액 카드 형태로 표시
통계방문 횟수·누적 금액, 월별 방문 차트, 시술 분포 차트

CSV 내보내기

고객 상세 화면 헤더의 ⬇ CSV 버튼을 탭하면 해당 고객의 시술 이력 전체를 엑셀 호환 CSV로 저장합니다. (시술 이력 1건 이상 존재 시 버튼 표시)

고객 정보 수정

고객 상세 헤더의 ✎ 버튼 → 수정 폼에서 이름, 전화번호, 이메일, 태그, 메모를 변경합니다.

5

상담 이력 작성 (ConsultationForm)

새 이력 작성 시작

1
고객 상세 화면 → + 상담 이력 추가

상담 이력 작성 폼(모달)이 열립니다.

2
이전 이력 자동 채우기 (선택)

재방문 고객이면 이전 값으로 채우기 버튼이 표시됩니다. 탭하면 직전 시술 정보가 채워져 수정만 하면 됩니다.

각 섹션 입력 요령

섹션입력 내용 및 팁
기본 정보 날짜(기본: 오늘), 스타일리스트 이름(필수). 드롭다운에서 지점 디자이너 선택.
시술 항목 종류 선택 → 설명 입력 → 금액 입력. + 항목 추가로 여러 시술을 동시에 기록. 모바일에서는 세로 스택으로 자동 정렬.
Before / After 사진 사진 영역 탭 → 카메라 또는 갤러리. 자동으로 압축되므로 원본 고해상도 그대로 업로드해도 됩니다.
모발 · 두피 상태 텍스트 직접 입력 또는 라벨 옆 🎤 버튼으로 음성 입력. (예: "손상도 심함, 두피 지성")
시술 포뮬러 컬러·펌 포뮬러를 기록. 🎤 음성 입력 지원. 저장된 포뮬러 템플릿에서 불러오기 가능.
상담 메모 고객 특이사항, 다음 방문 참고 사항 자유 기록. 🎤 음성 입력 지원.
다음 방문 예정 권장 재방문일을 입력하면 대시보드와 고객 홈에 알림 카드가 표시됩니다.

포뮬러 템플릿 저장 · 불러오기

1
포뮬러 입력 후 💾 템플릿 저장 탭

템플릿 이름(예: "내추럴 브라운 6N+8%")을 입력하고 저장합니다.

2
다음 작성 시 📂 템플릿 버튼 → 목록에서 선택

저장된 포뮬러가 자동으로 입력됩니다.

3
불필요한 템플릿은 목록 옆 🗑 버튼으로 삭제
💡
포뮬러 템플릿은 이 기기의 브라우저에 저장됩니다. 다른 기기에서는 공유되지 않으므로, 자주 쓰는 기기에서 저장하는 것을 권장합니다.

작성 중 이탈 방지

폼에 내용을 입력한 후 ✕ 닫기를 탭하거나 브라우저를 닫으려 하면 다음과 같이 동작합니다.

  • 모달 닫기 → "작성 중인 내용이 있습니다. 닫으시겠어요?" 확인 팝업 표시
  • 브라우저/탭 닫기 → 브라우저 기본 이탈 경고 표시
💡
갑자기 전화가 와서 앱에서 나가야 할 때도 데이터가 유실되지 않도록 항상 저장 또는 확인 팝업을 거치도록 되어 있습니다.

저장 완료

모든 항목 입력 후 저장 버튼을 탭합니다. 저장 성공 시 화면 하단에 토스트 메시지가 표시되고, 고객 상세 이력 목록이 자동 갱신됩니다.

6

상담 이력 상세 · 공유

상세 화면 구성

이력 목록에서 카드를 탭하면 상담 상세 화면이 열립니다. 헤더 우측 버튼:

버튼기능
🖨 인쇄브라우저 인쇄 다이얼로그 열기 (시술 카드 형태)
✎ 수정이력 수정 폼 열기
🗑 삭제이력 삭제 (확인 후 완전 삭제)

고객 수정·삭제 요청 처리

고객이 공유 링크를 통해 수정 또는 삭제 요청을 남기면 상세 화면 상단에 노란색 경고 배너가 표시됩니다. 요청 내용을 확인하고 처리 후 처리 완료 버튼을 탭하면 배너가 사라집니다.

고객 공유 링크 발급

1
상세 화면 하단 고객 공유 섹션 → 토글 켜기

공유가 활성화되면 고유 링크 URL이 생성됩니다.

2
복사 버튼 → 링크를 카카오톡·문자 등으로 전달
3
공유 중단 시 토글 끄기

링크가 즉시 만료됩니다.

ℹ️
공유 링크는 로그인 없이 열 수 있습니다. 고객의 개인정보가 포함되므로 신뢰할 수 있는 채널로 전달하세요.

예약 관리

예약 목록 확인

사이드바 예약 관리에서 지점의 전체 예약 목록을 확인합니다. 탭 필터로 상태별 조회 가능합니다.

탭표시 내용
전체모든 상태의 예약
대기미확인 신규 예약 (사이드바 배지 숫자로 표시)
확정승인된 예약
취소취소된 예약 이력

예약 확정 · 취소

1
예약 카드 탭 → 상세 팝업 열기
2
확정 또는 취소 버튼 선택

취소 시 취소 사유를 입력할 수 있습니다.

💡
예약을 확정하면 고객의 예약 탭에서 상태가 확정으로 바뀝니다. 가능한 빨리 처리하여 고객 혼란을 줄이세요.

예약 메모 수정

예약 상세에서 ✎ 버튼으로 희망 시간, 시술 항목, 메모를 변경할 수 있습니다.

내 정보 (프로필)

프로필 확인 · 수정

사이드바 내 정보에서 이름, 전화번호, 전문 분야, 경력 등을 확인·수정합니다. ✎ 수정 버튼 탭 → 변경 후 저장.

내 시술 통계

프로필 하단에서 본인의 시술 이력 통계를 확인합니다.

  • 이번 달 시술 건수 · 매출
  • 월별 추이 차트
  • 시술 종류 분포
ℹ️
통계는 전 지점에서 본인이 담당한 시술 전체를 포함합니다. 이직 전 이력도 함께 집계됩니다.
9

자주 묻는 질문 (FAQ)

질문답변
다른 디자이너 고객이 목록에 보이지 않아요. 일반 디자이너(staff)는 본인 담당 고객만 표시됩니다. 전체 고객을 보려면 원장에게 매니저 권한을 요청하세요.
사진을 올렸더니 화면이 느려요. 업로드 시 자동 압축이 적용됩니다. 매우 큰 사진 여러 장을 한 번에 올리면 잠깐 느릴 수 있으나 저장 후에는 정상입니다.
포뮬러 템플릿이 사라졌어요. 템플릿은 브라우저 localStorage에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기에서 접속하면 보이지 않습니다.
작성 중인 이력이 실수로 닫혔어요. 저장 전 작성 내용은 복구되지 않습니다. 이탈 방지 확인 팝업이 뜰 때는 반드시 취소 후 저장하세요.
고객이 공유 링크를 받지 못했어요. 상세 화면에서 공유 토글이 켜져 있는지 확인하고 복사 버튼으로 링크를 직접 전달하세요.
음성 입력이 작동하지 않아요. 브라우저 마이크 권한을 허용해 주세요. 브라우저 주소창 왼쪽의 자물쇠 → 마이크 → 허용.
